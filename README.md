# 🏥 NurSync — Nursing Education & Training Management Platform

**NurSync** is a full-stack web platform designed to centralize, coordinate, and manage educational and training activities for nursing staff across hospitals, solving the problem of fragmented training schedules and manual attendance tracking.

---

## 🚀 Key Features
- **Activity & Event Management:** Create, schedule, and manage hospital training sessions, workshops, and educational programs.
- **Staff Registration & Tracking:** Seamless registration workflow for nursing staff with automated attendance and participation tracking.
- **Centralized Dashboard:** Unified view for healthcare administrators and coordinators to monitor ongoing and upcoming activities.
- **Cloud Deployment:** Fully configured and deployed on cloud web servers with a relational MySQL database architecture.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** PHP
- **Database:** MySQL
- **Development Approach:** AI-Assisted Development & Prompt Engineering for rapid prototyping and clean architectural structuring.
